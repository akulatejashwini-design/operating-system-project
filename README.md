MEMORY MANAGEMENT STIMULATOR

The Memory Management Simulator is a web-based application designed to demonstrate and analyze
different memory management techniques used in operating systems. Instead of manually calculating
memory allocation and deallocation, this simulator provides a fast, visual, and automated solution.
The simulator supports:
• Multiple memory allocation algorithms (First Fit, Best Fit, Worst Fit)
• User input for memory block sizes and process sizes
• Automatic memory allocation
• Internal and external fragmentation analysis
• Memory block visualization
• Graph comparison of algorithm performance
This project demonstrates the use of core operating system concepts, memory allocation algorithms, and
interactive UI design.

Purpose of the Project
• To simulate memory management algorithms in a visual and interactive way
• To understand memory allocation and fragmentation
• To compare performance of different allocation techniques
• To automate memory allocation calculations
• To demonstrate use of arrays, loops, and logic building in JavaScript
• To improve understanding of real-time OS memory management behavior
